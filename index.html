Slider 1–10 sets a VVI threshold: threshold = 0.5×(n−5)+1.0, so 1 = −1.0, 5 = +1.0, 10 = +3.5. VVI scores are standard deviations from the national mean. Areas scoring above a threshold are flagged. Scores > 1.0 are considered high.

Flagged-area km on Interstate / US / SH-TX / Loop / Spur roads count at this fraction of local-road km (0.3 = 30%).

The free routing server can't hard-exclude roads, so Compass penalizes freeway, toll, and ferry km when scoring detours and picks waypoints that pull the route onto other roads. When “Avoid highways” is on, the highway preference above is ignored. The same options are added to the Google Maps link (avoid=). Before you drive, check ⋮ → Route options in the Maps app.

Limitations: avoidance is a preference — Compass tests detours 5–30 km to each side of the route (up to 3 waypoints) and picks the one with the least flagged distance within your max extra time; it cannot hard-block areas the way Maps avoids tolls. Google Maps may re-route between waypoints differently. The Google Maps link carries the route, not the shading (shading lives in My Maps via KML). Routing uses the public OSRM demo server and geocoding uses Nominatim (fair-use limits). VVI scores: Vizient Vulnerability Index 2026 public file (no login). Areas without data are shown grey and never flagged.
